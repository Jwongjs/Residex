# SplitLah Design Tokens

Use these values in Figma to ensure 1:1 visual fidelity with the app.

## 🎨 Color Palette

### Base
- **Background (Deep Slate):** `#020617`
- **Surface (Slate 900):** `#0f172a`
- **Surface Transparent:** `rgba(15, 23, 42, 0.4)`
- **Border White:** `rgba(255, 255, 255, 0.1)`

### Primary Accents
- **Cyan Primary:** `#22d3ee` (cyan-400)
- **Blue Accent:** `#2563eb` (blue-600)
- **Primary Gradient:** `linear-gradient(135deg, #22d3ee 0%, #2563eb 100%)`

### Trophy Tiers (Gradients)
- **Platinum:** 
  - Fill: `linear-gradient(135deg, #22d3ee 0%, #3b82f6 50%, #6366f1 100%)`
  - Stroke: `#a5f3fc`
- **Gold:**
  - Fill: `linear-gradient(135deg, #fcd34d 0%, #d97706 50%, #b45309 100%)`
  - Stroke: `#fcd34d`
- **Silver:**
  - Fill: `linear-gradient(135deg, #f1f5f9 0%, #94a3b8 50%, #475569 100%)`
  - Stroke: `#e2e8f0`
- **Bronze:**

  - Stroke: `#fdba74`

## 🖋️ Typography
- **Primary Font:** Inter
- **Headings:** 900 (Black) or 800 (Extra Bold)
- **Subheadings:** 700 (Bold)
- **Body:** 400 (Regular) or 500 (Medium)
- **Tracking:** 
  - Tighter (-0.02em) for Large Titles
  - Widest (0.1em) for Uppercase Labels

## ✨ Effects
- **Glow Blur:** 80px to 120px for ambient orbs.
- **Card Shadow:** `0 10px 15px -3px rgba(0, 0, 0, 0.5)`
- **Glassmorphism:** Blur 24px + 10% white stroke.
