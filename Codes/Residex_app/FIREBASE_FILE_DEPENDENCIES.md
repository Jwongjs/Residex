## 🚀 Compilation Order

**When running `flutter run`, files compile in this order:**

1. **pubspec.yaml** → Resolves all package dependencies
2. **firebase_options.dart** → Generated config loaded
3. **main.dart** → Entry point compiles
4. **core/theme/app_theme.dart** → Theme system compiles
5. **core/services/auth_service.dart** → Business logic compiles
6. **core/providers/auth_provider.dart** → State management compiles
7. **core/router/app_router.dart** → Routing compiles (triggers screen compilation)
8. **All screens/** → UI screens compile in dependency order
9. **Native bridges** → Android: Gradle builds APK, iOS: Xcode builds IPA
10. **App Launch** → Firebase initializes → Splash screen shows
