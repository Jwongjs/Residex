## Step 4: Configure Firebase for Flutter

Run this command in your Flutter project root:

```bash
cd C:\Users\user\Downloads\Residex-main\Residex-main\Codes\Residex_app\Residex_app

```

- ✅ Creates `lib/firebase_options.dart` with platform-specific config
- ✅ Generates `android/app/google-services.json` for Android
- ✅ Generates `ios/Runner/GoogleService-Info.plist` for iOS

## Step 5: Android Platform Setup

### 5.1 Verify `google-services.json`

**File Location:** `android/app/google-services.json`

Go Firebase console --> Project Overview --> Choose Residex android --> download google-service.json
**Same goes for Residex IOS

This file should be auto-generated by `flutterfire configure`. Verify it contains:

```json
{
  "project_info": {
    "project_number": "123456789",
    "project_id": "residex-app",
    "storage_bucket": "residex-app.appspot.com"
  },
  "client": [...]
}
```

### 5.2 Configure Root `build.gradle.kts`

**File:** `android/build.gradle.kts`

Add Google Services classpath:

```kotlin
buildscript {
    ext.kotlin_version = '1.9.10'
    repositories {
        google()
        mavenCentral()
    }

    dependencies {
        classpath("com.android.tools.build:gradle:8.1.1")
        classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:$kotlin_version")
        classpath("com.google.gms:google-services:4.4.2") // ← ADD THIS
    }
}
```

### 5.3 Configure App `build.gradle.kts`

**File:** `android/app/build.gradle.kts`

Add at the **END** of the file (after `dependencies` block):

```kotlin
dependencies {
    implementation(platform("com.google.firebase:firebase-bom:33.7.0"))
    implementation("com.google.firebase:firebase-analytics")
    implementation("com.google.firebase:firebase-auth")
    implementation("com.google.firebase:firebase-firestore")
    implementation("androidx.multidex:multidex:2.0.1")
}

// ⚠️ MUST BE AT THE VERY END
apply(plugin = "com.google.gms.google-services")
```

Enable MultiDex in `android` block:

```kotlin
android {
    defaultConfig {
        // ...
        multiDexEnabled = true
    }
}
```

### 5.4 Generate SHA-1 Fingerprint (CRITICAL)

Firebase Authentication **requires** SHA-1 fingerprint for Android.

```bash
cd android
./gradlew signingReport
```

**Output (look for "debug" variant):**
```
Variant: debug
Config: debug
Store: C:\Users\user\.android\debug.keystore
Alias: AndroidDebugKey
MD5: XX:XX:XX:...
SHA1: A1:B2:C3:D4:E5:F6:... ← COPY THIS
SHA-256: ...
```

### 5.5 Add SHA-1 to Firebase Console

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select **residex-app** project
3. Click **⚙️ Settings → Project Settings**
4. Scroll to **Your apps** section
5. Click on **Android app** (com.residex.app)
6. Click **Add fingerprint**
7. Paste SHA-1 value
8. Click **Save**

## Step 8: Verify main.dart Initialization

**File:** `lib/main.dart`

Ensure Firebase is initialized correctly with platform checks:

```dart
import 'package:flutter/material.dart';
import 'package:flutter/foundation.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_app_check/firebase_app_check.dart';
import 'firebase_options.dart';
import 'core/theme/app_theme.dart';
import 'core/router/app_router.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  // Initialize Firebase
  try {
    await Firebase.initializeApp(
      options: DefaultFirebaseOptions.currentPlatform,
    );
    print('✅ Firebase initialized successfully');

    // Initialize App Check ONLY on mobile/web (not Windows/macOS/Linux)
    if (!kIsWeb && (defaultTargetPlatform == TargetPlatform.android || 
                     defaultTargetPlatform == TargetPlatform.iOS)) {
      await FirebaseAppCheck.instance.activate(
        androidProvider: AndroidProvider.debug, // For development
        appleProvider: AppleProvider.debug, // For iOS development
        // For production:
        // androidProvider: AndroidProvider.playIntegrity,
        // appleProvider: AppleProvider.deviceCheck,
      );
      print('✅ App Check initialized (Mobile)');
    } else if (kIsWeb) {
      await FirebaseAppCheck.instance.activate(
        webProvider: ReCaptchaV3Provider('your-recaptcha-site-key'),
      );
      print('✅ App Check initialized (Web)');
    } else {
      print('⚠️ App Check skipped (Desktop platform)');
    }
  } catch (e) {
    print('❌ Firebase initialization error: $e');
    // Continue anyway for development
  }

  runApp(
    const ProviderScope(
      child: ResidexApp(),
    ),
  );
}
```

### Key Points:

- ✅ **Platform-aware App Check**: Only initializes on Android/iOS/Web
- ✅ **Error handling**: Catches initialization errors without crashing
- ✅ **Debug providers**: Uses `AndroidProvider.debug` for development
- ✅ **Production ready**: Comments show production configuration

## Step 10: Setup Firestore Security Rules

### 10.1 Via Firebase Console

1. Go to **☁️ Firestore Database**
2. Click **Rules** tab
3. Replace default rules with:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper function to check authentication
    function isSignedIn() {
      return request.auth != null;
    }
    
    // Helper function to check user role
    function getUserRole() {
      return get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role;
    }
    
    // Users collection - users can read/write their own data
    match /users/{userId} {
      allow read: if isSignedIn() && request.auth.uid == userId;
      allow create: if isSignedIn() && request.auth.uid == userId;
      allow update: if isSignedIn() && request.auth.uid == userId;
      allow delete: if false; // Prevent deletion
    }
    
    // Properties collection - landlords only
    match /properties/{propertyId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn() && getUserRole() == 'landlord';
      allow update: if isSignedIn() && getUserRole() == 'landlord' 
                      && resource.data.landlordId == request.auth.uid;
      allow delete: if isSignedIn() && getUserRole() == 'landlord'
                      && resource.data.landlordId == request.auth.uid;
    }
    
    // Leases collection
    match /leases/{leaseId} {
      allow read: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow create: if isSignedIn() && getUserRole() == 'landlord';
      allow update: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow delete: if isSignedIn() && resource.data.landlordId == request.auth.uid;
    }
    
    // Maintenance tickets
    match /maintenanceTickets/{ticketId} {
      allow read: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow create: if isSignedIn();
      allow update: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow delete: if false; // Audit trail - no deletions
    }
    
    // Bills collection
    match /bills/{billId} {
      allow read: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow create: if isSignedIn();
      allow update: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow delete: if isSignedIn() && resource.data.landlordId == request.auth.uid;
    }
    
    // Documents collection
    match /documents/{documentId} {
      allow read: if isSignedIn() && (
        resource.data.landlordId == request.auth.uid ||
        resource.data.tenantId == request.auth.uid
      );
      allow create: if isSignedIn();
      allow update: if isSignedIn() && resource.data.uploadedBy == request.auth.uid;
      allow delete: if isSignedIn() && resource.data.uploadedBy == request.auth.uid;
    }
  }
}
```

4. Click **Publish**

## Step 11: Setup Storage Security Rules

### 11.1 Via Firebase Console

1. Go to **🗂️ Storage**
2. Click **Rules** tab
3. Replace default rules with:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    
    // Helper function
    function isSignedIn() {
      return request.auth != null;
    }
    
    // User profile images
    match /users/{userId}/profile/{imageFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && request.auth.uid == userId
                     && request.resource.size < 5 * 1024 * 1024 // 5MB limit
                     && request.resource.contentType.matches('image/.*');
    }
    
    // Property images
    match /properties/{propertyId}/{imageFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() 
                     && request.resource.size < 10 * 1024 * 1024 // 10MB limit
                     && request.resource.contentType.matches('image/.*');
    }
    
    // Maintenance ticket images
    match /maintenance/{ticketId}/{imageFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn()
                     && request.resource.size < 10 * 1024 * 1024
                     && request.resource.contentType.matches('image/.*');
    }
    
    // Bill/receipt images
    match /bills/{billId}/{imageFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn()
                     && request.resource.size < 5 * 1024 * 1024
                     && request.resource.contentType.matches('image/.*');
    }
    
    // Lease PDFs
    match /leases/{leaseId}/{pdfFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn()
                     && request.resource.size < 20 * 1024 * 1024 // 20MB limit
                     && request.resource.contentType == 'application/pdf';
    }
    
    // Documents (AI-indexed)
    match /documents/{userId}/{documentFile} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && request.auth.uid == userId
                     && request.resource.size < 20 * 1024 * 1024;
    }
  }
}
```

4. Click **Publish**

## Troubleshooting

### ❌ Error: "No Firebase App"

**Symptom:**
```
[core/no-app] No Firebase App '[DEFAULT]' has been created
```

**Solution:**
1. Verify `firebase_options.dart` exists in `lib/`
2. Check `main.dart` has `await Firebase.initializeApp(...)`
3. Run `flutterfire configure` again

---

### ❌ Error: "MissingPluginException"

**Symptom:**
```
MissingPluginException(No implementation found for method FirebaseAuth#signInWithEmailAndPassword)
```

**Solution:**
1. Clean build: `flutter clean && flutter pub get`
2. Rebuild app: `flutter run`
3. Check `pubspec.yaml` has correct Firebase dependencies:
   ```yaml
   firebase_core: ^3.8.0
   firebase_auth: ^5.3.3
   cloud_firestore: ^5.5.2
   ```

---

### ❌ Error: "SHA-1 Fingerprint Missing"

**Symptom:**
```
FirebaseException: An internal error has occurred. [AUTHENTICATION_FAILED]
```

**Solution:**
1. Generate SHA-1: `cd android && ./gradlew signingReport`
2. Copy SHA-1 from "debug" variant
3. Add to Firebase Console → Project Settings → Android app → Add fingerprint

---

### ❌ Error: "Google Services Plugin Not Found"

**Symptom:**
```
Plugin [id: 'com.google.gms.google-services'] was not found
```

**Solution:**
1. Add classpath to `android/build.gradle.kts`:
   ```kotlin
   classpath("com.google.gms:google-services:4.4.2")
   ```
2. Ensure `apply(plugin = "com.google.gms.google-services")` is at **END** of `android/app/build.gradle.kts`

---

### ❌ Error: "App Check MissingPluginException" (Windows)

**Symptom:**
```
MissingPluginException: No implementation found for method FirebaseAppCheck#activate
```

**Solution:**
App Check is not supported on Windows desktop. Add platform check in `main.dart`:

```dart
if (!kIsWeb && (defaultTargetPlatform == TargetPlatform.android || 
                 defaultTargetPlatform == TargetPlatform.iOS)) {
  await FirebaseAppCheck.instance.activate(...);
}
```

---

### ❌ Build Fails with Java Version Error

**Symptom:**
```
Dependency requires at least JVM runtime version 11. This build uses a Java 8 JVM.
```

**Solution:**
1. Install [Eclipse Adoptium JDK 17](https://adoptium.net/)
2. Set `JAVA_HOME`:
   ```powershell
   # Windows
   $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.18.8-hotspot"
   ```
3. Update `android/gradle.properties`:
   ```properties
   org.gradle.java.home=C:\\Program Files\\Eclipse Adoptium\\jdk-17.0.18.8-hotspot
   ```

---

### ❌ Error: "FirebaseAuthException: missing-email"

**Symptom:**
Registration fails with "missing-email" error.

**Solution:**
Verify `AuthService.signUpWithEmail()` passes email to Firebase:

```dart
final userCredential = await _auth.createUserWithEmailAndPassword(
  email: email,
  password: password,
);
```
